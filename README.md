# Hardtack

> "The fire went out. The owl said nothing. But the hardtack was real, and we're still hungry."

Hardtack is a local-first, append-only context ledger for sovereign human-AI collaboration. It preserves your operational history across resets, verifies integrity with a hash chain, and runs entirely offline. No cloud. No black boxes. No subscriptions.

## Features

- **Append-only JSONL ledger** with SHA-256 hash chaining
- **Human-readable Markdown export**
- **Local search** across all entries
- **Integrity verification** (`hardtack verify`)
- **Zero external dependencies** — pure Python standard library
- **Offline-first** — works with no network
